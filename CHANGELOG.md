# Changelog

## 0.1.0

- Three guided paths: everyday decisions, group work, and communication.
- Interactive feedback simulation with saved controls and a text description.
- Draft restoration after navigation and reload.
- Practice notes, reflections, JSON export, and undo for the most recent removal.
- Duplicate-safe saving and validation of stored records.
- Responsive navigation, keyboard focus handling, skip link, reduced-motion support, and labelled dialogs.
- Self-contained assets with no third-party font requests.
- Dependency-free Node server, automated checks, and static-host deployment instructions.
